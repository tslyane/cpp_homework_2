# ФизКат

Консольная программа для учёта техники в парке. С её помощью можно добавлять и удалять предметы, смотреть список инвентаря, считать энергопотребление и находить транспорт для новичков.

## Сборка и запуск

```bash
g++ -std=c++17 main.cpp Inventory.cpp Transport.cpp Thing.cpp ServiceCenter.cpp -o physcat
./physcat
```

## Команды

- `add bike id name score` — добавить велосипед;
- `add scooter id name energy score` — добавить электросамокат;
- `add ebike id name energy score` — добавить электровелосипед;
- `add helmet id name` — добавить шлем;
- `add dock id name energy` — добавить зарядную станцию;
- `list` — показать весь инвентарь, отсортированный по ID;
- `energy` — вывести общее суточное энергопотребление;
- `novice` — показать транспорт, подходящий новичкам;
- `focus id` — выбрать предмет для витрины;
- `show_focus` — показать выбранный предмет;
- `remove id` — удалить предмет;
- `count` — посчитать количество предметов каждого типа;
- `quit` — выйти из программы.

ID предметов должны быть уникальными. Оценка новичка задаётся от 1 до 10, энергопотребление не может быть отрицательным. Перед добавлением транспорт проходит техосмотр: если в названии есть `broken`, он не попадает в парк.

## Реализация

`InventoryItem` — базовый абстрактный класс для всех предметов. `Transport` описывает общие свойства транспорта, а `Bike`, `ElectricBike` и `ElectricScooter` — его конкретные виды.

`EnergyConsumer` — интерфейс для предметов, которые потребляют энергию. Его реализуют электровелосипед, электросамокат и зарядная станция.

`Fleet` управляет инвентарём, а `ServiceCenter` отвечает за техосмотр. Благодаря виртуальным методам парк может работать с разными типами предметов через общий базовый класс.

## Умные указатели

- `unique_ptr` используется для передачи нового объекта в парк. Если техосмотр не пройден, объект автоматически уничтожается.
- `shared_ptr` хранит предметы в парке и позволяет нескольким единицам транспорта использовать общее описание модели `ModelSpec`.
- `weak_ptr` используется для витрины: он указывает на выбранный предмет, но не владеет им. Если предмет удалить из парка, витрина становится пустой.

## Шаблоны

Для хранения предметов используется шаблонный класс `Registry<T, Cap>`. Он ограничивает размер парка, поддерживает поиск и удаление, а также хранит элементы в порядке возрастания ID.

Шаблонная функция `calculateEnergy` считает суммарное энергопотребление объектов, реализующих `EnergyConsumer`.

## Исключения

Используется собственная иерархия исключений: `FleetError` — базовый класс, от которого наследуются `InspectionError` и `CommandError`.

Первый отвечает за ошибки техосмотра, второй — за ошибки команд и аргументов. Исключения обрабатываются в `main()`.

## Дополнительная функциональность

Добавлена команда `count`, которая показывает количество предметов каждого типа и их общее количество.
